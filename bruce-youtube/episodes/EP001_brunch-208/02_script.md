어느 기자가 그 장면을 SNS에 올렸어요. / 테이프가 덕지덕지 붙은 광고판 사진이었죠.

그런데 한 브랜드가 이걸 그냥 지나치지 않았습니다. / 케첩 브랜드, Heinz(하인즈)요.
자기 로고를 검은 테이프로 가린 케첩병을 / 그대로 제품으로 내놓았어요. / 이름은 Unofficial Stadium Ketchup(언오피셜 스타디움 케첩), / 비공식 스타디움 케첩입니다.

재미있는 건 이겁니다. / 로고가 가려져 있는데도 / 우리는 이게 하인즈인 걸 압니다. [쉼]

## CH02 1만 달러짜리 하이재킹 (01:30-03:55)

하인즈가 이런 일을 처음 한 건 아닙니다. / 2022년 카타르 월드컵으로 돌아가 볼게요.

그때 하인즈는 Thomas Heinz(토마스 하인즈)라는 사람을 찾아냈습니다. / 이름이 같은, 그러니까 동명이인이에요. / 빨간색과 흰색 옷을 입은 이 사람이 경기장 곳곳에 나타났고, / 사람들은 'Where's Waldo(웨어즈 월도)', 우리말로 '월리를 찾아라' 하듯 / 그 사람을 찾아다녔습니다.

광고제 출품 자료에 따르면 결과는 이렇습니다. / 노출 **1,400만 회**, 도달 **700만 명 이상.**

숫자보다 놀라운 건 예산이에요. / 이 캠페인에 쓴 돈이 **1만 달러**, / 공식 스폰서십이 보통 1,000만에서 2,500만 달러라고 하니까 / 그 천분의 일 수준입니다.

여기서 정리하고 싶은 게 있어요. / 두 캠페인을 나란히 놓으면 공통점이 보입니다. / 둘 다 **스폰서가 되어서 이긴 게 아니라, 스폰서가 아닌 채로 이겼다**는 거죠.
큰 돈을 들여 공식 자리에 앉는 대신 / 규칙이 만든 빈틈에 / 아이디어 하나를 넣었어요.

비교 사례를 하나 더 볼게요. / 2013년 슈퍼볼 정전 때 Oreo(오레오)가 올린 / "어둠 속에서도 덩크할 수 있다"는 트윗, 기억하시나요? / 이것도 같은 구조입니다. / 일이 벌어진 바로 그 순간에, 비용 없이 들어간 거죠.

그런데 저는 여기서 이야기를 끝내고 싶지 않습니다. / 이건 '재치 있는 마케팅' 이야기로 소비하기 쉬운데요, / 진짜 궁금한 건 **왜 하필 케첩이냐**는 겁니다.

비교 사례가 말해 주는 건 하나입니다. / 이런 캠페인의 본체는 돈이 아니라 **타이밍과 시선**이라는 거예요. / 다만 타이밍만으로는 설명이 안 됩니다. / 같은 빈틈을 모두가 봤는데, 왜 하인즈만 가져갔을까요. / 그 답은 뒤에서 이야기하겠습니다.

한 가지만 더 짚을게요. / 이 캠페인들을 본 사람들이 기억하는 건 / 케첩의 맛이나 성분이 아닙니다. / **'아, 하인즈 또 재밌는 거 했네'**라는 느낌이에요. / 광고가 제품 설명을 하지 않는데도 / 오히려 브랜드가 더 또렷해집니다. / 설명하지 않아도 되는 브랜드가 가장 강한 브랜드라는 말이 / 이럴 때 실감 나요.

## CH03 매대 앞에서 고민이 없는 제품 (03:55-06:05)

마케팅에서 제품을 나눌 때 / '관여도'라는 말을 씁니다. / 구매하기 전에 얼마나 깊이 고민하고 비교하느냐는 뜻이에요.

집이나 자동차는 고관여죠. / 평생 몇 번 사지 않고, 잘못 사면 타격이 크니까요. / 은행도 비슷합니다. / 한번 정한 곳을 관성으로 오래 쓰는 사람이 많으니까요. / 이런 카테고리에서 브랜딩이 중요하다는 건 / 누구에게나 자연스럽습니다.

반대편에 저관여 제품이 있습니다. / **케첩이 대표적이에요.**
대부분의 사람은 매대 앞에서 오래 고민하지 않습니다. / 선호하는 맛이 있는 사람도 있겠지만, / 다른 걸 집어 와도 큰 차이를 못 느끼는 경우가 많죠.

그리고 이런 카테고리에서 흔히 나오는 마케팅 논리가 있어요. / "품질이 비슷하니 결국 가격이다. / 그러니 브랜딩 말고, 매출을 바로 끌어오는 광고에 돈을 쓰자." / 실무에서 정말 자주 듣는 말입니다. [쉼]

하인즈의 선택은 정반대예요. / 고민이 없는 제품일수록 **브랜딩에 더 진심**입니다. / 왜일까요?

제 해석은 이렇습니다. / 고민이 없다는 건, / 비교하고 따져서 고르지 않는다는 뜻이잖아요. / 그러면 사람은 무엇으로 고를까요. / **그냥 먼저 떠오르는 것, 익숙한 것, 어디선가 한 번 마주친 것**입니다.

이걸 아주 일상적인 장면으로 옮겨 볼게요. / 퇴근길 편의점에서 / 물이나 휴지, 케첩 같은 걸 집을 때 / 우리가 가격표를 꼼꼼히 비교하던가요? / 거의 손이 먼저 움직입니다. / **그 손이 어디로 가는지를 정하는 게 바로 브랜딩**이에요.

품질 차이가 느껴지지 않는 곳에서는 / 기억이 곧 선택 기준이 돼요. / 그래서 저관여일수록 / 머릿속에 먼저 떠오르는 자리를 차지하는 게 / 거의 전부가 됩니다.

다시 말해 하인즈의 이상한 열정은 / 광고 감각이 좋아서가 아니라 / **계산이 맞아서** 나오는 행동이라고 저는 봅니다. / 고민 없이 집는 제품에서는 / 그 순간 떠오르는 브랜드가 곧 매출이니까요.

## CH04 1등이기 때문에 가장 많이 보여야 한다 (06:05-08:20)

하인즈는 미국 케첩 시장에서 / 점유율 **60% 이상**을 가진 1등으로 알려져 있어요. / 케첩이라는 말이 사실상 브랜드 이름과 겹쳐 쓰일 정도입니다.

그러면 이렇게 물을 수 있죠. / "이미 1등인데 왜 저렇게까지 하지?" [쉼]
제 답은 반대입니다. / **1등이라서 안 해도 되는 게 아니라, 1등이니까 가장 많이 보여야 한다.**

카테고리의 대명사 자리는 / 한번 차지하면 끝나는 게 아니거든요. / 매일 지키는 겁니다. / 그 자리는 사람들 머릿속의 '첫 번째 떠오름'이고요, / 그건 노출이 멈추는 순간부터 / 조용히 줄어들기 시작합니다.

이 이야기가 저한테 낯설지 않은 이유가 있어요. / 제가 일했던 클라이언트 중에 / 어느 카테고리에서 1등이던 브랜드가 있었습니다. / 효능도, 신뢰도도, 가격 경쟁력도 앞섰어요. / 그런데 경쟁사가 공격적으로 브랜드 이미지를 끌어올리는 동안 / 그 브랜드는 카테고리의 대명사 자리를 내줬습니다.

숫자로는 여전히 1등이었어요. / 하지만 소비자가 **'첫 번째로 떠올리는 브랜드'**가 아니게 된 순간 / 그 숫자가 흔들리기 시작했습니다. / 그리고 한번 밀린 인식은 / 되돌리기가 정말 어렵더군요.

여기서 많은 분들이 이렇게 반문하세요. / "1등 브랜드니까 가능한 얘기 아닌가요?" / 맞아요, 절반은 맞습니다. / 하지만 순서를 뒤집어 보면 달라집니다. / 하인즈가 1등이라서 노출하는 게 아니라, / **계속 노출했기 때문에 1등을 지키고 있는 것**일 수도 있잖아요. [쉼] / 닭이 먼저냐 달걀이 먼저냐 같은 얘기지만, / 실무자는 이걸 '지키는 비용'으로 계산해야 합니다.

물론 반례도 있습니다. / 하이재킹은 **언제나 통하는 공식이 아니에요.** / 하인즈의 두 캠페인이 먹힌 건 / 이미 병 모양만으로 알아볼 수 있는 브랜드 자산이 있었기 때문입니다. / 로고를 가려도 알아보는 브랜드라서 / '로고를 가린 케첩'이 성립한 거죠.
자산이 없는 브랜드가 따라 하면 / 그냥 이상한 병 하나가 됩니다.

## CH05 우리 브랜드는 어떻게 떠오르고 있는가 (08:20-11:00)

정리해 볼게요. / 저는 이 사례에서 세 가지를 봅니다.

첫째, 저관여 제품일수록 **브랜딩이 사치가 아니라 생존 전략**이라는 것. / 품질이 비슷한 곳에서는 / 떠오르는 방식이 곧 경쟁력이에요.
둘째, 가격과 퍼포먼스 광고만으로 싸우는 브랜드는 / 더 싼 제품이 나오는 순간 흔들립니다. / 가격은 언제든 누군가 더 낮출 수 있으니까요. / 반면 **기억은 쉽게 복사되지 않아요.**
셋째, 1등도 쉬지 않는다는 것. / 점유율은 결과이고, 인식은 계속 관리해야 하는 과정입니다.

저는 팀에서 이런 말을 자주 듣고, 직접 하기도 했습니다. / "이번 분기는 일단 판매부터 올리자. 브랜딩은 나중에." / 그 판단이 틀렸다고 말하려는 건 아니에요. / 다만 그 '나중에'가 / 몇 번 반복되면 / 어느새 소비자 머릿속에서 우리 자리가 사라져 있습니다. [쉼] / 매출 광고와 기억을 쌓는 일은 / 둘 중 하나를 고르는 문제가 아니라 / **비율을 정하는 문제**예요.

그리고 하나 더, 가격 이야기를 하고 싶어요. / 브랜드 인식이 단단한 제품은 / 조금 비싸도 선택받습니다. / 이유는 간단해요. / 사람들은 가격을 비교하기 전에 / 이미 마음속으로 한 번 고르고 있으니까요. / 반대로 인식이 약한 브랜드는 / 가격표 앞에서 매번 처음부터 설득해야 하고요. / **그 설득 비용이 쌓이면, 브랜딩에 쓰는 돈보다 훨씬 큽니다.**

그럼 실무에서는 뭘 할 수 있을까요. / 큰 예산이 없어도 시작할 수 있는 질문 세 개를 드릴게요.

하나. **우리 제품의 어떤 요소가 로고를 가려도 알아볼 만한가?** / 색일 수도, 모양일 수도, 말투일 수도 있어요.
둘. **우리 카테고리에서 사람들이 가장 먼저 떠올리는 브랜드는 누구인가?** / 그게 우리가 아니라면, 그 이유를 매출 말고 인식에서 찾아보세요.
셋. **지금 쓰는 광고비 중, 기억을 쌓는 데 쓰는 돈은 얼마인가?** / 전부 당장의 클릭에만 쓰고 있지 않은지 / 한 번쯤 따져 볼 필요가 있습니다.

제가 이 글을 처음 썼을 때 마음에 남았던 문장이 있어요. / 마케팅은 매출을 만드는 일이기 이전에, / **소비자와 관계를 맺는 일**이라는 겁니다. / 매출은 그 관계의 결과로 따라오는 거고요.

하인즈는 케첩을 팔지 않습니다. / 케첩을 사야 하는 순간에 / **먼저 떠오르는 자리**를 팝니다. [쉼]

그래서 마지막으로 / 저한테 던지는 질문이기도 하고, 여러분께 드리는 질문이기도 합니다.
