# EP005 V2 평가 계획

## 가설
V2 편집 문법(0~3초 실제 장면, 15초 안 질문+보상, 5~6분 압축, 3~7초 화면 변화)은 V1(10~15분 영상 에세이) 대비 **30초 유지율(R30)**을 높인다. 성과 개선을 보장하지 않으며, 아래 교란 요인 때문에 인과로 단정하지 않는다.

## 비교안
- **V1 비교군:** 기존 포맷 영상 4개(EP001~EP004 계열 — 이미 예약·공개된 것, 수정하지 않음). 영상 ID·공개 시각은 `metrics_template.csv`에 공개 후 채운다(현재 미연결).
- **V2:** EP005 본편.
- **공개 전 비교(내부):** Hook A vs Hook B 첫 30초 미리보기(`preview_hook_A.mp4`, `preview_hook_B.mp4`). 본편 이후는 동일. 음성 A/B(`voice_ab.md`)와 따로 평가한다. 단순 선호 점수를 유지율로 부르지 않는다.
  평가 기준(1~5): 이해한 질문 / 약속한 보상 / 계속 볼 이유 / 과장 여부.

## 고정 요소
채널명·BGM·자막 스타일·Bruce 복제 목소리(multilingual_v2)·출처 표기 방식.

## 지표
- 주요: R30(30초 시점 유지율)
- 보조: APV(평균 조회율), AVD(평균 시청 시간), 15·60초 유지율, 노출 CTR, 주요 하락 지점, 유입 경로, 신규/재방문 구성
- 변화는 %p와 상대 변화를 구분(예: 50%→55% = +5%p, 상대 +10%). V1 4개는 중앙값·범위를 먼저 보고, 길이가 다른 영상의 유지율 곡선을 그대로 평균내지 않는다.

## 관찰 기간
공개 후 48시간, 7일, 28일. 도달하지 않은 기간은 '미수집'. 표본이 적으면 '판단 유보'.

## 교란 요인
길이(V1 10~15분 vs V2 5분대 — APV는 길이만으로도 달라짐), 주제 시의성(BIFF 발표 직후), 제목·썸네일, 유입 경로, 공개 요일·시각, 노출 규모, 채널 초기 구독자 변화, 같은 주 인스타그램 릴스 노출.

## 다음 변경 1개
R30이 V1 중앙값보다 낮으면 → Hook B 방식(원문 인용 첫 문장)으로 다음 V2 1편을 만들어 비교. 높으면 → 길이만 7~8분으로 늘린 V2로 APV 하락 폭 확인.

플랫폼 실험 기능(제목·썸네일 테스트)은 계정에서 실제 지원·승인될 때만 쓰고, 같은 본편을 중복 업로드하지 않는다.
