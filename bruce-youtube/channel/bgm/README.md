# 채널 BGM

- `bgm.mp3` — 브루스 인사이트 영상 에세이 공통 배경음악(약 2분, 연주곡).
- ElevenLabs Music(eleven_music_v2_5)으로 생성(2026-10-08). 프롬프트: 잔잔한 다큐멘터리 언더스코어, 약 90 BPM, 펠트 피아노 + 아날로그 패드, 보컬 없음.
- 받아쓰기(eleven_scribe_v1)로 보컬이 없는 것을 확인했다.
- render가 영상 길이만큼 4초 크로스페이드로 이어 붙이고(-27 LUFS), 내레이션이 나올 때 자동으로 약 10dB 줄인다(사이드체인).
  챕터 간지·마지막 4초 여운에서는 다시 올라오고, 처음 1.5초 페이드인·마지막 4초 페이드아웃.
- 바꾸려면 이 파일만 교체한다. 없으면 BGM 없이 렌더된다.
