# 브루스 인사이트 YouTube 채널 개설 키트

인스타그램 @bruce.insight와 같은 이름·색·마크로 맞춘다. 채널 개설은 Google 계정 로그인이 필요해 직접 한다(약 10분).

| 파일 | 용도 | 규격 |
|---|---|---|
| `profile.png` | 프로필 사진 (BR. 마크) | 800×800 |
| `banner.png` | 배너 | 2560×1440, 글자는 가운데 안전 영역 1546×423 안 |
| `thumbnail-sample.png` | 썸네일 형식 예시 (EP001 하인즈) | 1280×720 |
| `render.mjs` | 위 이미지를 다시 그리는 스크립트 | `node bruce-youtube/channel/render.mjs` |

디자인: 아이보리 `#F2F1ED`, 민트 `#65B98A`, 라벨 초록 `#23744c`, 검정 `#111`, Pretendard 900. 인스타그램 카드 렌더러(`src/lib/card-renderer.js`)와 같은 값.

## 1. 채널 만들기

1. PC에서 youtube.com 로그인 → 오른쪽 위 프로필 → **설정** → **새 채널 만들기**(또는 youtube.com/channel_switcher → 채널 만들기)
   - 개인 Google 계정 이름이 아닌 **브랜드 계정**으로 만든다. 채널 이름을 따로 쓸 수 있고, 나중에 관리자를 추가할 수 있다.
2. 채널 이름: **브루스 인사이트**
3. 핸들: `@bruce.insight` (인스타그램과 동일). 이미 쓰이고 있으면 `@bruceinsight` → `@bruce_insight` 순서로.
4. YouTube 스튜디오 → **맞춤설정**
   - 브랜딩: 사진 `profile.png`, 배너 `banner.png`
   - 기본 정보: 아래 설명·링크 붙여넣기
5. 스튜디오 → 설정 → 채널 → **고급 설정**: 시청자층 "아동용 아님", 국가 대한민국
6. 휴대전화 인증(스튜디오 → 설정 → 채널 → 기능 사용 자격요건) — 15분 넘는 영상, 맞춤 썸네일에 필요

## 2. 채널 설명 (그대로 붙여넣기)

```
광고 뒤의 판단을 읽습니다.

브루스 인사이트는 마케팅·브랜드·콘텐츠 사례를 10년 넘게 현장에서 일한 마케터의 시선으로 해석하는 영상 에세이 채널입니다.
"무엇이 떴나"보다 "왜 그런 판단을 했나"를 이야기합니다.

▸ 브랜드 사례 — 캠페인 하나를 맥락·판단·결과로 뜯어봅니다
▸ 마케터의 판단 — 기획 회의에서 실제로 마주치는 질문들

매주 한 편, 10~15분.

인스타그램 @bruce.insight
브런치 brunch.co.kr/@heoboram
홈페이지 bruceheo.com
```

## 5. 업로드 기본값 (스튜디오 → 설정 → 업로드 기본설정)

- 공개 범위: **비공개**로 올린 뒤 확인하고 공개 (예약 공개 권장: 릴스와 같은 날 07:00)
- 카테고리: 교육 / 언어: 한국어 / 자막 언어: 한국어
- 태그: 마케팅, 브랜딩, 광고, 브랜드 사례, 마케터, 캠페인, 콘텐츠 마케팅, 브루스 인사이트
- 설명 기본 문구:

```
브런치 원문 ▶ {브런치 링크}

00:00 {챕터}
…

인스타그램 @bruce.insight · 브런치 @heoboram
```

챕터 타임코드는 `01_brief.md`의 Chapter Structure를 녹음 길이에 맞춰 고친 값을 쓴다.

## 6. 운영 원칙

- **변경되거나 합성된 콘텐츠 표시**: Higgsfield로 만든 사실적인 장면(실제처럼 보이는 사람·장소)이 들어가면 업로드 화면의 "변경된 콘텐츠"에 **예**. 추상 그래픽·타이포만이면 표시 대상이 아니다.
- **실제 광고 인용**: 비평·해설 목적으로 한 번에 10초 이내, 화면에 출처 표기. 음악이 나오는 구간은 피하거나 음소거(Content ID 소유권 주장 대비).
- **광고주 실명·내부 수치 금지** (인스타그램과 동일).
- 릴스·Shorts 캡션에 "풀버전은 유튜브 브루스 인사이트" 한 줄을 넣어 본편으로 연결한다.
