콘텐츠는 새롭게, 링크 규칙은 일정하게.

도착 페이지와 캠페인 이름을 입력하면 5개 채널의 추적 링크를 한 번에 만듭니다.
이 도구는 휴대폰과 PC의 브라우저에서 작동하며 입력 내용을 외부로 보내지 않습니다.

새 글은 실제 글 주소를 넣으세요. 예: https://bruceheo.com/writing/223/
아래의 utm_content 값은 개별 수정할 수 있습니다.
고정 소개: profile_always_on · 새 콘텐츠: content_YYYYMMDD_주제영문
예: content_20261020_ai_daily — 같은 콘텐츠를 여러 채널에 올릴 때 같은 이름을 유지하세요.

매번 이렇게 사용하세요

  1. 고정 프로필 링크는 현재 기본값으로 생성해 붙여 넣으세요.
  2. 새 글을 홍보할 때는 도착 페이지를 글 주소로 바꾸고, 게시 위치를 ‘새 글’로 선택하세요.
  3. 캠페인을 content_날짜_주제로 바꿉니다. 날짜는 8자리, 영문은 소문자, 단어 사이는 밑줄을 씁니다.
  4. 채널별 링크를 복사해 해당 채널의 링크 입력란이나 본문에 넣으세요. 표시 문구는 ‘전체 글 읽기’처럼 짧게 해도 됩니다.
  5. GA4 트래픽 획득에서 ‘세션 소스/매체’와 ‘세션 캠페인’을 확인하세요. 문의 성과는 핵심 이벤트 contact_click로 좁혀 봅니다.

홈페이지 안에서 페이지를 이동하는 링크에는 UTM을 붙이지 마세요. UTM은 외부에서 홈페이지로 들어오는 방문을 구분합니다. 링크 노출 수, 외부 채널 구독, 실제 이메일 발송 완료는 이 링크만으로 측정되지 않습니다.
