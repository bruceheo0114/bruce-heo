## 승인 뒤 순서

1. 릴스: 편마다 내레이션 2테이크 → 테이크 고르기 → 장면 이미지 3장 → 클립 1개 → 샌드박스 합성 → QA 시트 확인 → `insight-reels/posts/<날짜>.json`(scheduled, 캡션·쇼츠 키트 포함) → 장부 기록 → 미리보기 메일.
2. 롱폼: `youtube.js prebuild` 로 Episode 생성 → 대본 반영·소리 내어 읽기 검사 → 챕터별 내레이션·받아쓰기 → 장면 7장 + 클립 → render → mp4·썸네일·upload.md 전달.
3. 결과물은 편마다 바로 보내고, 게시 전날 07:00 전까지 `보류 MM/DD` 회신으로 멈출 수 있다.
