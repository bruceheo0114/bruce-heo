## 상태값
`pending`(승인 대기) → `scheduled`(게시 대기) → `posted` / `hold`(보류).
- 원고는 `scheduled` 로 만든다(사용자 결정 2026-10-05: 승인제 없이 자동 게시). 회신 없으면 매일 12:30 에 올라가고, "보류"·"수정" 회신만 반영한다.

## 목소리
- **반말 구어체, 1인칭.** 쓰는 사람은 10년 넘게 에이전시에서 IMC 캠페인을 해 온 마케터 브루스. 가르치는 말투가 아니라 현장에서 겪은 걸 털어놓는 말투("~더라", "~거든", "~했어").
- 단정은 하되 과장은 하지 않는다. 존댓말·"여러분" 금지(마지막 질문도 반말: "너네 팀은 어때?", "다들 어떻게 해?").

## 3초 오프닝 (사용자 결정 2026-10-05, 릴스·카드뉴스와 공통 원칙)
- **첫 줄 15~25자로 스크롤을 멈춘다.** 정보·설명으로 시작하지 않는다.
- **둘째 줄까지 "끝까지 읽을 이유"를 남긴다.** 답을 바로 주지 않는다(예: "근데 그게 실수가 아니었어"). 연 질문은 본문에서 꼭 답한다(낚시 금지).

## 구조: 공감 → 문제 제기 → 전환 → 결과 (본문 300~450자, 최대 480자 — 공백·줄바꿈 포함, `len()` 으로 센다)
1. **훅**(첫 줄)
2. **공감**: 읽는 사람이 겪어 봤을 상황 1~2줄
3. **문제 제기**: 왜 다들 여기서 틀리는지 1~2줄
4. **전환**: 원문 속 사례·판단이 뒤집는 지점. 바로 앞에 다음이 궁금해지는 한 줄("근데 진짜 이상한 건 그다음이었어", "여기서 갈려")
5. **결과**: 한 줄 원칙(가장 저장하고 싶은 문장)
6. **끝**: 답하기 쉬운 질문 1줄. 주 2~3회는 질문 뒤에 자연스러운 저장·팔로우 한 줄을 더한다(예: "다음 제안서 쓰기 전에 다시 보게 저장해 둬", "이런 현장 얘기 매일 점심에 올려"). 매일 넣지 않는다.
- 1~2문장마다 빈 줄. 한 문단 2줄 이내.

## 훅 7가지 패턴 — 요일마다 돌린다
| 요일 | 패턴 | 예 |
|---|---|---|
| 월 | 실패 경험형 | 밈 하나 터뜨렸는데, 브랜드는 아무도 기억 못 했어. |
| 화 | 반전형 | 실수처럼 보였는데, 설계였더라. |
| 수 | 숫자형 | 조회수 200만인데 수세미 얘기는 한 줄도 없었어. |
| 목 | 비밀 공개형 | 제안서 통과하는 팀은 RFP를 거꾸로 읽어. |
| 금 | 질문형 | AI한테 제품을 물어봐, 상황을 물어봐? |
| 토 | 비교형 | 팔로워 100만 vs 댓글 100개, 뭘 고를래? |
| 일 | 논란형 | 반복은 게으름이 아니야. |
- 저장·공유가 잘 나오는 비밀 공개형·비교형·숫자형을 아끼지 않는다. 그 요일에 원문에 숫자나 비교 거리가 없으면 다른 패턴으로 바꾸고 `hook_type` 에 실제 패턴을 적는다.
- 논란형은 통념에 반대하는 소신이다. 사람·브랜드를 비난하지 않는다.
- 숫자·비밀·사례는 원문에 있는 것만. 없는 "비밀"을 만들지 않는다.

## posts/DATE.json
```json
{"date": "YYYY-MM-DD", "brunch_no": 0, "title": "원문 제목", "hook_type": "반전형",
 "text": "본문(480자 이내)", "topic_tag": "마케팅",
 "reply_text": "사례 전체랑 숫자는 브런치에 정리해 뒀어 👉 https://brunch.co.kr/@heoboram/0",
 "status": "scheduled"}
```
- `topic_tag` 는 하나만: 마케팅 / 브랜딩 / 콘텐츠마케팅 / 커리어 / AI 중에서. 본문에 해시태그를 쓰지 않는다.
- 원문 링크는 본문에 넣지 않는다(첫 댓글 `reply_text`). 댓글은 광고·부탁처럼 쓰지 않고 "더 읽을 거리"로 안내한다(원문에 있는 것만: "체크리스트까지 써 뒀어", "실제 숫자는 여기 정리해 뒀어" 등). 매번 같은 문장을 쓰지 않는다.

## 지킬 것
- 사실은 원문에 있는 것만. 숫자·주체·순서를 바꾸지 않는다. 광고주(클라이언트) 실명·내부 수치는 "한 브랜드"로.
- 옛 글(2021~2024)의 "올해·최근·요즘 화제" 같은 시의성 표현은 지금 읽어도 맞게 고친다. 지금 읽으면 틀린 내용이면 그 글은 skip.
- 연차·나이·직책처럼 **쓴 시점 기준인 자기 정보**는 과거형으로 쓴다("10년 차인데" ✗ → "10년 차 됐을 때" ○). 원문 작성일은 `brunch_cache/index.json` 의 date.
- 금지: "댓글 남기면 DM" 같은 반응 미끼, "무조건·충격·역대급" 과장, 이모지 2개 이상(댓글의 👉 제외), 남 비꼬기·정치·사회 논란.
- 같은 주에 같은 훅 문장 패턴을 반복하지 않는다.
