# 트렌드 노트 매주 발송 (직접 예약)

스티비 요금제는 **스탠다드**(구독자 ~500명, 발송 무제한, 자동 이메일 가능)다.
새 이메일을 만들고 예약하는 **이메일 API 는 프로 요금제부터**라 쓰지 않는다. 화요일 루틴은 원고까지만 만들고, 스티비 예약은 브루스가 직접 한다.
자동 예약 워크플로 `trend-note-stibee.yml` 은 꺼 둔다(끄는 방법·프로로 올릴 때: `SETUP.md` 5절).

## 주간 흐름

| 언제 | 누가 | 할 일 |
|---|---|---|
| 화 18:07 | Actions `trend-note-naver.yml` | 네이버 국내 사례 후보 수집 |
| 화 19:52 | Claude 루틴 | 원고 4파일 커밋 → 「원고 메일」 발송 |
| 화 밤 ~ 수 07:50 | **브루스 10분** | 아래 「직접 예약」 |
| 수 08:00 | 스티비 | 예약 발송 |
| 수 아침 | 브루스 | LinkedIn 뉴스레터 게시(`linkedin.md`) |

## 원고 메일에 들어 있는 것 (루틴이 만든다)

- 스티비 제목: `[트렌드 노트 #<호수>] <제목>` (그대로 복사)
- **HTML 복사용 링크**: `https://raw.githubusercontent.com/bruceheo0114/bruce-heo/main/newsletter/trend/<날짜>/email.html`
  열면 HTML 원문만 글자로 보인다. 전체 선택 → 복사.
- 미리보기 링크 `https://bruceheo.com/newsletter/trend/<날짜>/`, 확인할 것(다룬 브랜드, 확인 못 한 숫자)

## 직접 예약 (PC 권장, 10분)

1. 다룬 브랜드 목록 확인 — 고객사·직접 경쟁 제품군이 있으면 보내지 않는다.
2. 스티비 → 이메일 → 지난 호 이메일 오른쪽 메뉴 → **복사**. 주소록 `브루스의 트렌드 노트`, 발신자, HTML 템플릿이 그대로 따라온다.
3. **발송 정보** → 제목을 원고 메일의 스티비 제목으로 바꾼다. 미리보기 텍스트는 비워 둔다(HTML 맨 위 숨김 문장이 쓰인다).
4. **콘텐츠** → HTML 편집기 안을 전체 선택해 지우고, 복사용 링크에서 복사한 HTML 을 붙여넣는다. 「모든 변경내용을 저장했습니다」 확인.
5. **테스트 발송** → `heoboram0114@gmail.com` 한 곳. 휴대폰 메일 앱에서 헤더 이미지·버튼·수신거부 링크 위치를 본다(수신거부는 테스트 메일에서 동작하지 않는 게 정상).
6. **예약하기** → 수요일 08:00.

## 휴대폰으로 할 때

스티비는 앱이 없고 편집 화면이 PC 웹 기준이다. 휴대폰 브라우저로도 로그인·복사·예약은 되지만 2~4단계(특히 HTML 붙여넣기)가 불편하다.
휴대폰에선 **예약 확인·취소**만 하고, 붙여넣기가 필요한 주는 화요일 밤에 PC 로 끝낸다.
꼭 휴대폰으로 해야 하면: 복사용 링크를 길게 눌러 전체 선택 → 복사 → 스티비 콘텐츠 편집기에 붙여넣기 → 테스트 발송으로 깨지지 않았는지 확인.

## 보내지 않을 때

스티비 → 이메일 → 해당 호 → **예약 취소**. 루틴 쪽은 따로 할 일이 없다(웹 아카이브 `bruceheo.com/newsletter/trend/<날짜>/` 는 이미 공개돼 있다. 내리려면 Claude 에게 말한다).
