## 1. 주소록 만들기

- 주소록 이름: `브루스의 트렌드 노트`
- 발신자 이름: `브루스의 트렌드 노트` (또는 `브루스(허보람)`)
- 발신자 이메일: `heoboram0114@gmail.com` (스티비 안내에 따라 발신 이메일 인증)
- 회사/단체명: `허보람(브루스)` · 주소·연락처는 스티비 필수 입력값대로
- 구독자 정보 필드: 이메일(필수), 이름, **사용자 정의 필드 `job` "하시는 일"** — 선택지 `브랜드사` / `대행사` / `기타`
- 더블 옵트인(구독 확인 메일): 켜기 권장 (스팸 주소 걸러짐)

## 2. 구독 폼 / 구독 페이지 문구

- 제목: `브루스의 트렌드 노트`
- 설명:
  ```
  트렌드 요약은 이제 AI도 몇 초면 해 줍니다. 이 노트는 그다음을 씁니다.
  매주 수요일 아침, 국내외 사례 4~5개를 형식이 아니라 반응의 이유로 읽어 드려요.
  구독하면 'AI 검색 브랜드 진단 시트'를 바로 보내 드립니다.
  ```
- 버튼: `구독하고 진단 시트 받기`
- 개인정보 수집·이용 동의(필수):
  ```
  수집 항목: 이메일, 이름, 하시는 일
  수집 목적: 「브루스의 트렌드 노트」 발송, 구독자 유형 통계
  보유 기간: 구독 해지 시까지 (해지 즉시 파기)
  동의를 거부할 수 있으나, 거부 시 뉴스레터를 받을 수 없습니다.
  ```
- 광고성 정보 수신 동의(선택): `책·강연·행사 소식을 함께 받겠습니다.`
- 완료 문구: `구독 확인 메일을 보냈어요. 메일의 버튼을 누르면 진단 시트가 도착합니다.`
- 로고: `wordmark-1200.png` · 공유 이미지: `cover-1200x630.png`
- 완료 후 이동 주소(선택): `https://bruceheo.com/newsletter/ai-search-check/?utm_source=stibee&utm_medium=form`

→ 만든 뒤 **구독 폼 공유 링크**(`https://page.stibee.com/subscriptions/...`)를 Claude에게 주면 홈페이지 구독 버튼에 넣는다.

## 3. 자동 이메일 (구독 환영 + 진단 시트)

- 종류: 자동 이메일 → 트리거 `구독자가 추가되었을 때` (주소록: 브루스의 트렌드 노트)
- 제목: `[구독 선물] AI 검색 브랜드 진단 시트를 보내 드려요`
- 템플릿: **HTML 에디터로 만들기** → `newsletter/stibee/welcome.html` 전체 붙여넣기

## 4. 수요일 발행 (매주)

- 새 이메일 → 주소록 `브루스의 트렌드 노트` → 템플릿 **HTML 에디터로 만들기**
- 본문: `newsletter/trend/<날짜>/email.html` 전체 붙여넣기 (미리보기 텍스트·웹에서 보기·수신거부 치환자 포함)
- 제목: `[트렌드 노트 #<호수>] <제목>` — #1: `[트렌드 노트 #1] AI가 정답을 골라주는데, 사람들은 왜 더 '나한테 맞는 것'을 찾을까?`
- 테스트 발송으로 본인에게 먼저 확인 → 수요일 08:00 예약 발송
- 참고: 수신거부 링크는 테스트 발송에서는 동작하지 않는다(스티비 도움말).
