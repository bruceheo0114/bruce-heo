# 생활픽노트 운영 지침

이 폴더는 쿠팡 전용 Threads `daily.picknotes`만 담당한다. 브루스 인사이트 인스타그램과 `heo.boram` Threads의 원고·토큰·자동화 파일을 변경하거나 재사용하지 않는다. 실제 새 username/user_id가 확정되면 config에 반영한다.

상품은 공식 상품 페이지의 정보·실측·제약을 확인해 소개한다. 출처·확인 시각 없는 가격/할인/재고/평점, 실제 없는 사용 경험·후기를 만들지 않는다. 상품 링크는 본인 쿠팡 파트너스 포털에서 발급한 링크만 사용한다. 원고는 draft로 작성하고 상품 정보·링크·광고 표시를 확인한 뒤 scheduled로 전환한다.

광고 문구는 게시기가 첫머리에 붙인다. 링크를 광고 문구와 다른 댓글로 분리하지 않는다. 프로필 소개에만 광고 표시를 넣고 개별 글에서 생략하지 않는다. 다른 사람에게 DM·댓글 광고를 자동 발송하지 않는다.

계정 연결 전에는 실제 게시하지 않는다. 토큰·앱 시크릿·인증 코드를 파일/채팅/커밋에 기록하지 않는다. needs_review 상태를 확인 없이 지우거나 재시도하지 않는다.
